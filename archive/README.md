# Legacy Code Archive

This directory preserves the historical snapshot of scripts and source code used for initial experiments prior to peer review revision for the *Journal of Real-Time Image Processing* (JRTIP).

- `legacy_scripts/`: Original runners, profiling, table generation, and PowerShell scripts (`.ps1`).
- `legacy_src/`: Original pipeline components (`runner.py`, `seed_manager.py`, etc.).

Do not edit files in this directory. New production implementations, SLURM scripts, and bug-fixed runners reside under `scripts/` and `src/`.
